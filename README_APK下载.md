# 📱 APK 下载与安装（云端自动构建，无需开发环境）

本 App 由 GitHub Actions 自动编译，**你不需要安装 Android Studio 或任何开发工具**，
直接在手机上点链接下载安装即可。

## 二、系统要求

| 项目 | 要求 |
|---|---|
| Android 版本 | **10（API 29）及以上** |
| CPU 架构 | **arm64**（2017 年之后的机型基本都是） |
| 存储空间 | 约 120MB（APK 约 50MB + 首次启动解压神经网络约 50MB） |
| 网络 | 安装后使用**完全不需要联网** |

> 为什么是 Android 10 起？因为随 APK 打包的 Pikafish 引擎二进制本身声明了
> 最低 API 29。这是引擎的限制，不是 App 代码的限制——App 代码是按
> Android 5.0 写的，将来用 NDK 重新编译引擎就能下探，代码一行都不用改。

## 三、安装步骤

1. 手机浏览器打开上面的下载页
2. 下载 `xiangqi-overlay-release.apk`
3. 系统提示"未知来源"/"允许安装未知应用" → **选择允许**
4. 安装完成后打开 App

## 四、首次使用（按顺序做）

### 第 1 步：给悬浮窗权限

App 内点「去开启」→ 跳到系统设置 → 允许**「显示在其他应用上层」**。

> **小米 / 红米用户注意**：HyperOS 上这个权限藏得比较深，除了上面那项，
> 还要在「设置 → 应用设置 → 应用管理 → 本应用 → 权限管理 → 其他权限」里
> 额外打开**「后台弹出界面」**，否则悬浮窗会莫名其妙不显示。

### 第 2 步：启动辅助并给截屏权限

点「启动悬浮窗辅助」→ 系统弹出录屏确认 → 点允许。

> **小米 / 红米**：会连续弹两次（系统录屏确认 + 隐私确认），**两次都要点允许**。
> 如果之后发现识别出来的画面是纯黑，通常是这一步没给全权限，重新走一遍即可。

启动后应该能在屏幕上看到一个小面板（就是悬浮窗）。如果没看到，
点主界面的「诊断信息」，里面会直接写明失败原因。

### 第 3 步：自动识别棋盘（什么都不用做）

**v1.4 起默认免标定**：

1. 切到你要用的象棋 App，**开一盘新的对局**（棋子摆成初始阵型）
2. 让棋盘完整显示两三秒，App 会自动找到棋盘四角并生成识别模板
3. 成功时会弹提示「已自动识别棋盘，无需手动标定」，悬浮窗随即开始给建议

> 自动识别的前提是画面里有**完整的初始局面**——这是防止认错棋盘的安全校验。
> 如果你打开的是一盘下到一半的棋，自动识别不会成功；此时开一局新棋、
> 或点面板「标定」手动框选即可。

### 第 3 步备用：手动标定（自动识别不好使时才用）

点**悬浮窗小面板上的「标定」按钮**，屏幕会盖上全屏标定画面
（内容是刚截到的棋盘）→ **拖动 4 个角点**框住棋盘最外圈的 4 个交叉点 →
选「我方是红方 / 黑方」→ 点「确认标定」。每个象棋 App 只需一次。

> 标定层是全屏悬浮窗，会临时挡住下面的象棋 App，确认或取消后立即恢复。

### 第 4 步：开始下棋

切回象棋 App 正常对局。悬浮窗会自动：

1. 检测到对手落子 → 截屏识别整个局面
2. 用手机本地的 Pikafish 引擎算出你的应手
3. 在悬浮窗上显示「对手走了什么 / 建议你走什么」，并在棋盘上画出落点箭头
4. **你自己手动落子**，它继续跟下一步

> 悬浮窗小面板可以按住标题栏拖动，也可以点「收起」缩成一小条。
> 它默认放在左上角，建议拖到棋盘**外面**（比如棋盘上方的空白区），
> 免得挡住棋子。

## 五、保活设置（重要，否则会被系统杀掉）

这类 App 必须常驻后台，而国产 ROM 对后台管得很严。**小米 / 红米**需要：

- 设置 → 应用设置 → 应用管理 → 本应用 → **省电策略 → 无限制**
- 允许本应用**自启动**
- 在最近任务列表里给本应用**加锁**（下拉卡片点锁图标）

其他品牌（华为 / OPPO / vivo）操作类似，App 内也做了对应的跳转引导。

## 六、关于自动构建

APK 由 GitHub Actions 云端编译，无需本地开发环境。

- 构建配置：`.github/workflows/build-android.yml`
- 向 `master` 分支推送代码会自动重新编译，并更新 Releases 页面
- 也可在仓库 **Actions** 页面选 **Build Android APK → Run workflow** 手动触发

**签名说明**：首次构建时会在 CI 内用 `keytool` 生成一个自签名证书并缓存下来，
之后每次构建都复用同一证书。因此新版本 APK 可以**直接覆盖升级，不需要卸载重装**。

## 七、常见问题

**Q：装的时候提示"解析包错误"？**
A：多半是下载不完整。重新下载一次，注意文件应有约 50MB。

**Q：装的时候提示"应用未安装"或签名冲突？**
A：之前装过别的版本。先卸载旧版再装。

**Q：悬浮窗不显示？**
A：按顺序排查三处——
①「显示在其他应用上层」是否真的开了（进设置页亲眼确认，别只信 App 里的检测）；
②小米/红米还要额外开「后台弹出界面」；
③回到 App 点「诊断信息」，里面会写明"悬浮窗：未显示"以及具体失败原因。

**Q：标定画面上看不到棋盘（是黑的 / 是别的画面 / 提示没有画面）？**
A：标定用的是"最近一张象棋 App 在前台时的画面"。请先切到象棋 App、
打开一盘棋、让棋盘完整显示**两三秒**，然后点悬浮窗面板上的「标定」。
如果这张画面仍是旧的，点「取消」，再回象棋 App 停一下重新点标定。

**Q：点「标定」就闪退？**
A：v1.2 及更早是「后台启动页面崩溃」，v1.3 在 Android 16 上仍有标定层空指针崩溃。
**v1.4 已双重修复**：标定层纯代码构建 + 全方法兜底，理论上不再可能因标定崩溃进程。
请升级到 v1.4 或更高版本，并默认走「自动识别棋盘」路线（连标定都不用点）。

**Q：自动识别棋盘一直不成功？**
A：自动识别要求画面里是**完整的初始局面**（新开的一局）。请开一盘新对局、
让棋盘完整显示几秒。如果仍不成功（个别 App 棋盘样式特殊），点面板「标定」
手动框选一次即可，之后就不用再管。

**Q：给了权限还是不行，怎么反馈？**
A：主界面点「诊断信息」→ 点「复制」，把内容发过来即可。里面包含机型、
系统版本、两项权限检测的原始值、各子系统的实际运行状态、最近一次错误，
**以及最近一次崩溃的完整堆栈**（v1.3 新增），能直接定位问题。

**Q：提示"引擎需要 Android 10 及以上"？**
A：随 APK 打包的引擎二进制要求 Android 10+。App 本身在老系统上能装能用，
但引擎跑不起来，所以暂时给不出建议。

**Q：识别不准 / 认错棋子？**
A：先确认标定的四个角是否准确框住了棋盘四角。棋子缩略图较小、或棋盘有动画时
识别率会下降。App 在不确定时会明确提示，而不是硬给一个错误建议。

**Q：能不能自动帮我落子？**
A：不能，也不打算做。本 App 只做提示，落子始终由你自己完成。
自动操作其他 App 属于平台高风险行为，可能违反游戏条款。
